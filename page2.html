Case and punctuation are folded, so Blue Panda and blue-panda are one pet. Letters are not folded: eminö and emino are different people and get different pets, which is the whole point of a lookalike check. The name is hashed with SHA-256 and the digest is sliced into independent fields. The phrase reads one set of bits; the three-emoji code reads a set the phrase never touches, so matching one does not hand an attacker the other. There are 559,054,848 phrases and 4,410,780 emoji codes, about 51 bits together. Check both, and check the address too. A pet that looks right is not proof; a pet that looks wrong is a reason to stop.
